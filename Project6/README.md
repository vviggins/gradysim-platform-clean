# Project6：负载扰动下的鲁棒性（本项目版）

## 目的
在固定 V 下，评估算法应对任务到达强度变化的自适应与稳定性。

## 设置
- 自变量：到达强度倍率 λ ∈ {0.6×, 0.8×, 1.0×, 1.2×, 1.4×}（基于基准到达率或任务大小上界 A_max）。
- 因变量：长期平均性能（能耗/延迟）与长期平均队列长度。
- 固定：V 取 Project5 推荐值，带宽、信道、能耗/延迟模型等保持不变。

## 步骤
1) 选定 V，固定环境与随机种子。  
2) 逐个负载倍率运行到稳态，记录平均性能与平均队列。  
3) 画两条曲线：性能 vs 负载倍率，队列 vs 负载倍率；必要时叠加置信区间。

## 输出
- 数据表：负载倍率, 平均性能, 平均队列。  
- 图：负载倍率 vs 性能/队列。

## 判据
性能和队列随负载上升可控增长，无发散或震荡，体现在线鲁棒性。
